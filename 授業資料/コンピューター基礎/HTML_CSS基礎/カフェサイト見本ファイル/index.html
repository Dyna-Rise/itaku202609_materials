私たちのこだわり

Cafe Soleilでは、豆の選定から抽出方法まで、すべてにおいて妥協しません。世界中から厳選したスペシャルティコーヒーを、丁寧にハンドドリップで提供しています。あなたの一日の始まり、あるいは終わりの時間が、特別なものになりますように。
