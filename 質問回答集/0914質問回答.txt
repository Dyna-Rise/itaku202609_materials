練習問題3-14について

3-14の問題で、for分を使って偶数だけ表示するプログラムを作ったのですが、
変数iを2つずつ増やしていくやり方だったのでした。
これは偶数分進めて、それを表示しているのでそうなるのはわかるのですが、
1ずつ進めて偶数を判断する方法はあるのでしょうか？
自分はifにi=0 || i=2 || i=4を詰め込んで力技で偶数を表示したのですが、
大きな数になった場合この方法ではよろしくない気がします。
何かいい方法を教えていただけますでしょうか。


→
            //0～100まで繰り返し
            for (int i = 0; i <= 100; i++)
            {
                //もし偶数なら表示
                //剰余計算が有効
                if (i % 2 == 0)
                {
                    Console.WriteLine(i);
                }
            }
